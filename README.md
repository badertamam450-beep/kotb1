# 📖 تطبيق كتاب «ابدأ من الصفر: فالحياة لا تهب الأماني»
### إعداد وتأليف: الدكتور / مالك عبدالرحمن الرميمة

تطبيق أندرويد متكامل وتفاعلي مبني بأحدث التقنيات الرسمية (**Jetpack Compose** و **Material 3**) ومخصص للعمل بأعلى كفاءة وسلاسة على **Android 15 (SDK 35/36)**.

---

## 🌟 مميزات التطبيق

1. **القراءة المتكاملة لجميع صفحات الكتاب (24 صفحة كاملة)**:
   - عرض فصول الكتاب بنصوص واضحة وتنسيقات عربية أنيقة.
   - وضع القراءة الليلي والنهاري (Dark/Light Mode).
   - التحكم في حجم الخط والتباعد وتخصيص تجربة القراءة.

2. **الاستماع الصوتي الذكي (Text-to-Speech)**:
   - إمكانية تشغيل القراءة الصوتية للنصوص باللغة العربية مع إمكانية الإيقاف المؤقت والاستئناف.

3. **شواهد القرآن الكريم والأحاديث النبوية**:
   - إبراز الآيات القرآنية الكريمة بتصميم بطاقات إسلامية مريحة للعين مع ذكر السورة ورقم الآية بدقة.

4. **ورقة عمل تفاعلية وخطة السنوات الأربع**:
   - قسم مخصص لتطبيق منهجية الكتاب العملية (رصد المشاريع، دراسة الجدوى، والبداية من الصفر) مع حفظ محلي آمن.

5. **فهرس ذكي وبحث سريع**:
   - فهرس تفاعلي للوصول الفوري لأي فصل أو عنوان داخل الكتاب مع إمكانية حفظ الإشارات المرجعية (Bookmarks).

6. **يعمل بدون إنترنت (100% Offline-First)**:
   - جميع نصوص وفصول الكتاب والوظائف تعمل مباشرة على الجهاز دون الحاجة لأي اتصال بالإنترنت.

## 📱 التوافق والمتطلبات التقنية

- **نظام التشغيل المدعوم**: Android 7.0 (API 24) فما فوق، ومُحسّن خصيصاً لـ **Android 14 و Android 15 (API 35)**.
- **لغة البرمجة**: Kotlin 2.0+
- **واجهة المستخدم**: Jetpack Compose مع Material Design 3
- **إصدار Gradle**: 8.11.1
- **JDK**: Java 17

## ⚙️ أسرار وبيانات الاعتماد على GitHub (GitHub Secrets)

إذا أردت توقيع التطبيق بمفتاحك الخاص (Release Keystore) عبر GitHub Actions، يمكنك إضافة المتغيرات التالية في:
`Settings -> Secrets and variables -> Actions -> Repository secrets`:

| المتغير السري (Secret Name) | الوصف | القيمة الافتراضية إذا لم يُحدد |
|---|---|---|
| `KEYSTORE_BASE64` | ملف الـ Keystore مشفر بصيغة Base64 | يتم إنشاؤه تلقائياً أثناء البناء |
| `CM_KEYSTORE_PASSWORD` | كلمة مرور الـ Keystore | `android` |
| `CM_KEY_ALIAS` | الاسم المستعار للمفتاح (Key Alias) | `upload` / `androiddebugkey` |
| `CM_KEY_PASSWORD` | كلمة مرور المفتاح الخاص | `android` |
| `GEMINI_API_KEY` | مفتاح Gemini API (اختياري) | يتم إنشاؤه تلقائياً فارغاً |

## 🛠️ البناء التلقائي وتحميل الـ APK عبر GitHub Actions

يحتوي المستودع على مسار عمل جاهز في المسار:
`/.github/workflows/android_build.yml`

### خطوات تحميل ملف الـ APK:
1. عند كل `git push` إلى المستودع، يبدأ البناء تلقائياً في تبويب **Actions**.
2. بعد اكتمال البناء وظهور علامة النجاح الخضراء ✅:
3. ادخل على تشغيل البناء، ثم انتقل إلى أسفل الصفحة إلى قسم **Artifacts**.
4. اضغط على ملف **`Ebda-Men-Al-Sefr-APK`** لتحميل الـ APK وتثبيته مباشرة على هاتفك.
